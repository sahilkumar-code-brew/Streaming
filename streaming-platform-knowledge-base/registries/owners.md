# Owners (AUTHORITATIVE)

> Single source of truth for who keeps which docs true. Frontmatter `owner:` must be a role from this table. Reference it: `registries/owners.md`

| Role | Person | Owns |
|------|--------|------|
| architect | unassigned | registries/, instructions/, CLAUDE.md, cross-surface log entries |
| backend-lead | unassigned | backend services, `architecture/api-contracts.md`, `contract-changes.md` rows |
| mobile-lead | unassigned | mobile-app docs, mobile column in `contracts.md` |
| admin-lead | unassigned | admin-web docs, admin column in `contracts.md` |

Owner of a doc = the role that re-verifies it when it goes stale. Swap in real names when the team grows.
